プライバシーポリシー

対象と運用者

このポリシーは、GitHubアカウント hawkeyes8512 の運用者が本人用に利用するHermesのGoogle連携を対象とします。

アクセスする情報と目的

本人がGoogleの同意画面で許可した範囲で、カレンダー、メール、Google Driveのファイル、ドキュメント、スプレッドシートの情報にアクセスします。情報は本人が依頼した予定管理、情報整理、文書作業、メール作業などの支援に利用します。

保存と外部サービスへの送信

認証情報は運用者が管理する実行環境に保存します。取得した情報や処理結果は、設定と操作内容に応じて会話履歴、ログ、記憶、バックアップ等に保存される場合があります。また、回答生成や情報処理のため、必要な情報が利用中の外部AIサービス等へ送信される場合があります。送信先の保持・利用条件には各サービスの規約と設定が適用されます。

利用制限

Googleから取得した情報は、本人の作業支援のために利用し、販売、広告配信、第三者向けのデータ提供を目的としません。Google API Services User Data PolicyのLimited Use要件を含む適用ポリシーに従って取り扱います。

保存期間と削除

保存期間は会話履歴・記憶・ログ・バックアップと利用サービスの設定に応じます。一律の自動削除期限は定めていません。運用者本人が保存設定や削除を管理します。Google側でアクセス権を取り消すと今後のアクセスを停止できますが、それだけで既に保存された履歴やバックアップが削除されるわけではありません。

公開サイトと問い合わせ

この公開サイトにはGoogleアカウントのデータや認証情報を掲載せず、独自のアクセス解析や広告を設置しません。ホスティング提供者のGitHubは、そのプライバシーポリシーに従ってアクセス情報を取り扱う場合があります。運用者の連絡先はGitHubプロフィールです。
